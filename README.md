# Finney

English-first Next.js rebuild of Construction Finney. Preview only. Not live on constructionfinney.ca.

Public facts, photos, phone, email, address, team names, RBQ number, and the Judith L. quote come from https://www.constructionfinney.ca/. Quote requests go to the printed mailto and tel. This preview does not copy their Wix questionnaire.

```
npm install
npm run dev
```

Live preview: https://construction-finney-preview.netlify.app
